# 비교 검증 프로토콜 v0.3

두 윤문 후보를 비교할 때는 같은 원문, 보호 구간, 목표 표지, 번역 원문 유무를 사용한다. 먼저 결정적 gate를 통과하지 못한 후보는 자연스러움 비교 대상이 아니다.

1. 원문의 입력 내력·장르·형식과 후보별 적용 모드를 기록한다.
2. 후보별로 보호값 보존, 목표 표지 전후 차이, 새로 생긴 표지, 변경량을 기록한다.
3. 수정 대상 표지가 줄지 않은 후보는 부적격이다. 문맥상 보존하려면 표지별 사람 확인과 사유가 필요하다.
4. gate 통과 후보만 원문과 함께 순서를 가린 검토에 올린다.
5. 검토자는 자연스러움, 의미 보존, 저자 목소리, 장르·격식, AI식 공식성, 과교정을 각각 판정한다. 사용자가 `reader_profile`을 제공했으면 같은 profile을 평가자에게 주고 독자 적합성도 별도로 판정한다.
6. `raw_ai`와 `human_polished`를 따로 집계한다. 전자는 해체 실행력, 후자는 절제를 시험한다.
7. 저자 추정, 탐지기 점수, AI 회피 여부는 기록하지 않는다. 장문에서 전개를 비교할 때에는 선택적으로 약속·전환·끝 상태의 보존을 기록하되, 모델 심사를 최종 선호 판정으로 쓰지 않는다.

비교 도구는 승자를 자동으로 정하지 않는다. 동률, 불확실한 문맥, 의미·리듬 판단은 확인 요청으로 남긴다. 모델을 평가자로 쓴 경우는 `model-assisted blind review`로 표시하고 사람 평가와 구분한다.

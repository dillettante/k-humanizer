# 비교 검증 프로토콜 v0.1

두 윤문 후보를 비교할 때는 같은 원문, 같은 보호 구간, 같은 목표 표지, 같은 번역 원문 유무를 사용한다. 먼저 결정적 gate를 통과하지 못한 후보는 자연스러움 비교 대상이 아니다.

1. 후보별로 보호값 보존, 목표 표지 전후 차이, 변경량을 기록한다.
2. gate 통과 후보만 순서를 가린 사람 검토에 올린다.
3. 검토자는 자연스러움, 장르·격식 보존, 의미 변경 유무, 기계적 표지 완화만 판정한다.
4. 저자 추정, 탐지기 점수, AI 회피 여부는 기록하지 않는다.

비교 도구는 승자를 자동으로 정하지 않는다. 동률, 불확실한 맥락, 의미·리듬 판단은 확인 요청으로 남긴다.

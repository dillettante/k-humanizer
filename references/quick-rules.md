# 빠른 규칙 v0.1

`quick-rules.json`은 모델이 다시 읽어 볼 **위치 후보**를 찾는 결정적 앵커다. 발견 횟수는 저자 판정, 품질 점수, 자동 수정 권한이 아니다. `KH-S05`처럼 넓은 문맥 판단이 필요한 표지는 의도적으로 빠른 규칙에서 제외한다.

| 표지 | 앵커 | 적용 전 확인 | 기계적 처방 |
| --- | --- | --- | --- |
| KH-S01 | `~가 아니라` | 실제 대조인가, 같은 기능의 반복인가 | 없음 |
| KH-S02 | 결산 상투구 | 새 결론을 전달하는가 | 없음 |
| KH-S03 | 첫째·둘째 등 | 절차·요건·목록인가 | 없음 |
| KH-S04 | 문두 연결어·재정의 | 앞문장과 실제 관계가 있는가 | 없음 |
| KH-S06 | `~에 의해` | 번역 원문이 제공됐는가 | 없음; 원문 없으면 스캔 제외 |
| KH-S07 | 연결어미 뒤 쉼표 | 인용·삽입·호흡인가 | 없음 |
| KH-S08 | 같은 종결 연속 3문장 이상 | 의도한 격식·화자 말투인가 | 없음 |
| KH-S09 | 반복된 완곡 표현 | 불확실성이 실질적인가 | 없음 |

직접 인용 안의 앵커, 수치·날짜·조문을 포함하는 후보는 기본 스캔에서 제외한다. 스캐너가 놓치는 표지는 “없음”이 아니라 “결정적 앵커 없음”을 뜻한다.

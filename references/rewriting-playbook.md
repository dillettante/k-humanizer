# 한국어 인간화 윤문 처방집 v0.3

## 1. 편집 순서

표준 인간화와 목소리 복원은 다음 세 번의 편집을 분리해 수행하라.

### 1차: 빼기

- 새 정보 없는 결산 라벨·중요성 평가·안내문을 지운다.
- 기능 없는 문두 연결어와 중복 완곡을 덜어 낸다.
- 형식 프로필이 허용하지 않는 이모지·과잉 볼드·장식성 헤딩을 제거한다.
- 삭제 뒤 논리 관계가 사라지면 삭제를 취소하고 2차 편집에서 구조를 고친다.

### 2차: 다시 짜기

- 먼저 문단의 주장·근거·예시·조건·예외·부정·양태·인과 관계·정도 수식·권고 강도를 `의미 명세`로 적는다. 원문에 없는 명제는 문체를 좋게 만드는 재료로도 추가하지 않는다. 다만 원문의 어구·어순·포장은 고정대로 쓰지 말고, 명세의 논리 관계와 판단 강도를 유지하는 범위에서 직접적으로 다시 쓴다.
- 추상 명사와 만능 동사를 가까운 주체·행위·조건으로 돌린다.
- 실제 순서가 아닌 첫째·둘째·셋째를 문장 사이 관계로 바꾼다.
- 같은 시작·종결·길이의 문장은 뜻이 이어질 때만 합치거나 나눈다.
- 모든 문단이 요약→설명→결산 공식이면 근거·장면·반례가 있는 문단만 그 지점에서 시작하게 한다.
- `A보다 B`를 `A는 자동으로 B가 되지 않는다`처럼 범위가 넓은 명제로 키지 마라. 원문에 없던 `다시`, `반복`, `따라서`, `때문에`를 넣어 과정이나 인과를 만들지 마라.

### 3차: 목소리 복원

- 입력 안에서 가장 직접적이고 구체적이며 과장 없는 문장 3~8개를 찾는다.
- 그 문장들의 격식, 종결 범위, 질문·대구 사용법, 문장 길이 변화만 로컬 기준선으로 기록한다.
- 윤문한 구간이 그 범위보다 더 매끈하거나 더 문학적이면 되돌린다.
- 원문에 없는 구체적 사실·감정·비유·경험을 만들지 않는다.

### 재구성 후 의미 대조

1. 윤문본의 각 명제를 편집 전 `의미 명세`의 항목과 연결한다.
2. 연결할 수 없는 명제는 새 정보·해석·강화로 보고 지우거나 `ask`로 돌린다.
3. 원문 명세에는 있는데 윤문본에 연결되지 않은 항목은 누락으로 보고 복구한다.
4. 논리를 즐겁게 만들기 위해 넣은 문장이라도 원문에 대응하는 명제가 없으면 실패다.
5. 명제가 대응해도 `시사점을 제공한다`, `효율성을 제고한다`, `실천적 과제다`처럼 공식적인 포장을 그대로 남겼다면 재구성이 아니다. 의미 범위는 지키고 표현은 다시 쓴다.
6. 인접 문장에 같은 어근이 다시 나오는지, 서술어의 주체가 분명한지, `그저·단지·실은`같은 새 평가 부사를 넣지 않았는지 따로 읽는다.
7. 유사어라도 의미 범위나 판단 강도가 다르면 실패다. `상호작용→반응`은 행위 범위를 줄이고, `중요하다→도움이 된다`는 평가를 낮추며, `~한다→~할 수 있다`는 사실 주장을 가능성으로 약화한다. 세 변경은 자연스러워도 채택하지 않는다.

## 2. 빈출 전환 레시피

| 문제 | 피할 처리 | 권장 처리 |
| --- | --- | --- |
| `X에 대해 논의한다` | 유의어만 교체 | `X를 논의한다`, 문맥상 `X를 두고 논의한다` |
| `X를 통해 Y할 수 있다` | `통해`만 삭제 | 수단이면 `X로 Y한다`, 조건이면 `X하면 Y할 수 있다` |
| `중요한 역할을 한다` | `핵심적 기능을 수행한다`로 치환 | 무엇이 달라지는지 이미 있으면 직접 동사로 연결 |
| `이는 X를 의미한다` | `이것은`으로 바꿈 | 앞 문장에 흡수하거나 가리키는 명사를 명시 |
| `~다는 점에서 중요하다` | `~라는 측면에서 핵심적이다` | 이유와 결론을 직접 연결 |
| `결론적으로` | `종합하면`으로 교체 | 라벨을 지우고 결론 문장을 바로 둠 |
| `주목할 만하다` | `눈여겨볼 필요가 있다` | 근거가 말하면 삭제, 아니면 왜 중요한지 직접 서술 |
| `A가 아니라 B다` 반복 | 전부 다른 대구로 변주 | 중심 대조 하나를 남기고 나머지는 평서문으로 |
| `장점도 있지만 단점도 있다` | 양쪽 표현만 바꿈 | 근거의 무게와 남는 불확실성을 따로 서술 |
| `첫째·둘째·셋째` | 우선·다음·마지막으로 기계적 치환 | 순서가 아니면 문장 관계로 녹임 |
| `~할 수 있을 것으로 보인다` | 곧바로 단정 | 근거 강도에 맞춰 완곡 한 겹씩만 걷음 |
| `합의가 이루어졌다` | 무조건 행위자 창작 | 행위자가 문맥에 있으면 `당사자가 합의했다`, 없으면 결과 상태 유지 |
| `이 글에서는 살펴본다` | 다른 안내문으로 바꿈 | 필수 범위 선언이 아니면 논점으로 바로 들어감 |
| 같은 `~이다` 연속 | 종결어미 무작위 변주 | 문장 관계를 보고 합치거나 초점이 다른 문장만 구조 변경 |
| 과잉 불릿 | 불릿 기호만 삭제 | 절차·요건은 목록 유지, 설명 항목은 문단으로 연결 |
| 과잉 볼드 | 모든 볼드 삭제 | 문서 구조·정의·법적 강조는 보존하고 문장 중 장식만 해제 |

### 의미 보존을 핑계로 포장을 남기지 말 것

| 원문의 포장 | 실패한 윤문 | 채택 가능한 방향 |
| --- | --- | --- |
| `X는 중요한 과정이다. X가 Y를 가능하게 하는 핵심 수단이기 때문이다.` | `X는 중요한 과정이자 Y를 돕는 핵심 수단이다.` | `X가 Y를 돕는다. 그래서 X가 중요하다.`처럼 인과와 평가를 한 번씩만 남김 |
| `메모도 중요하다. 메모를 통해 내용을 정리하면 기억의 효율성을 제고할 수 있다.` | `메모도 중요하다. 주요 내용을 메모로 정리하면 효율적으로 기억할 수 있다.` | `메모도 도움이 된다. 주요 내용을 적어 두면 기억하기 쉽다.`처럼 어근 반복과 효율 포장을 함께 줄임 |
| `올바른 방식은 유연하게 조정되어야 하는 실천적 과제다.` | `올바른 방식은 유연한 실천 과제다.` | `목적에 따라 방식을 유연하게 바꾸어야 한다.`처럼 정도 수식과 권고 강도를 동사에 붙임 |

위 방향의 문구를 기계적으로 복사하지 말고, 원문의 주체·시제·양태·인과 관계에 맞춰 다시 쓴다.

## 3. 문단 편집 질문

문장별 치환 전에 문단에 다음을 물어라.

1. 이 문단은 상황·주장·근거·반례·귀결 중 무엇을 하고 있는가?
2. 첫 문장이 실제 초점인가, 자동 요약문인가?
3. 마지막 문장이 새 귀결인가, 앞말을 다시 포장했는가?
4. 연결어를 지우면 관계가 남는가? 남지 않으면 문장 구조가 문제다.
5. 구체적 자료가 있는데 추상 평가가 그 앞을 가리고 있지는 않은가?
6. 질문·대구·반복이 다음 문장을 움직이는가, 장식에 그치는가?

## 4. 장르 가드

| 장르 | 적극적으로 손볼 것 | 기본 보존 |
| --- | --- | --- |
| 단행본·에세이 | 결산 라벨, 도식적 병렬, 균일한 문단 공식, 대화형 서식 | 의도한 대구·장면·개인적 호흡 |
| 칼럼 | 의의 과장, 균형 봉합, 공식형 결말 | 논지의 선명한 단언·수사적 압축 |
| 보고서 | 불필요한 메타 안내, 중복 완곡, 추상 만능 동사 | 실제 목차·요약·논리 목록 |
| 법률 | 의미 없는 상투구와 중복 표현 | 단서·유보·요건 목록·인용·정의 |
| 학술 | 불필요한 영어 병기·명사화 중복 | 연구 범위 선언·전문용어·양태 |
| 블로그·SNS | 기계적 카드 구성과 상투적 호응 | 의도한 이모지·불릿·친근한 말투 |
| 번역 | 원어 구조의 기계적 흔적 | 원문의 모호함·반복·표지성 |

## 5. 실패 조건

다음 중 하나라도 생기면 해당 수정을 되돌리거나 `ask`로 남겨라.

- 사실·수치·인용·용어·행위자를 새로 만들거나 지움
- 부정·양태·인과·조건·예외의 강도가 달라짐
- 저자의 대구·반복·구어가 전부 평탄해짐
- 한 상투구를 다른 상투구로 바꿈
- 문장이 모두 비슷한 길이와 종결로 다시 수렴함
- 원문보다 격식을 올리거나 문학적 장식을 보탬
- DOCX의 의미 있는 제목·목록·강조를 단순 장식으로 오인함

## 6. 변경 기록

중요한 변경만 `위치 | 패턴 | 전후 요지 | 이유 | 보호·의미 검증`으로 기록하라. 변경 대장이 본문보다 길어지지 않게 하고, 완성된 윤문본을 먼저 제시하라.

# 최소 윤문 처방집 v0.1

진단 뒤에는 표지마다 하나만 고른다. `remove`와 `reshape`만 실제 변경이고, `preserve`와 `ask`는 변경하지 않는 결론이다.

| 처방 | 사용할 때 | 금지 |
| --- | --- | --- |
| `remove` | 새 정보 없이 반복되는 결산·연결 표지 | 논리 관계·강조를 함께 지우기 |
| `reshape` | 뜻은 맞지만 정보 순서나 문장 부담이 기계적인 경우 | 새 사실·비유·감정·문체 흉내 넣기 |
| `preserve` | 대구·반복·격식이 논증·리듬·장르 기능을 맡는 경우 | 억지로 변주하기 |
| `ask` | 주체·부정·양태·귀속·강조가 달라질 수 있는 경우 | 조용히 단정하여 고치기 |

윤문 뒤에는 `verify_protected_spans.py`와 `verify_style_gate.py`를 실행한다. 통과는 표지 감소만이 아니라 보호 구간 보존을 함께 뜻한다.

# 평가 계약 v0.10

## 목적

K-humanizer는 저자 판별이나 탐지기 회피를 평가하지 않는다. 평가는 문체 표지 완화와 의미·목소리 보존의 동시 달성 여부를 본다.

## 평가 집합

- 개발·검증·blind holdout은 문서 단위로 분리한다.
- 공개 fixture는 자작 또는 재배포가 허용된 자료만 쓴다.
- 음성 fixture에는 법률·학술 용어, 직접 인용, 자연스러운 반복, 구어체, 실제 목록을 넣는다.
- 번역 fixture는 원문이 있는 경우와 없는 경우를 분리한다.
- 용어 이관 fixture는 기존어 잔존, 확정어 구성어의 정의 반복, 정당한 용어 반복, 인용 예외, 연어의 사람 판정을 분리한다.
- scanner fixture에는 낱말 내부 오탐(`즉시·즉석`), 활용형 오탐(`아니라고`), HTML 주석, fenced code, Markdown 인용 조문, 명시 보호 블록을 넣는다.
- 다파일 fixture에는 manifest의 누락 파일·중복 ID·제외 이유를 넣고, coverage fixture에는 표본·전수 기계 분류·전수 사람 문맥 검토를 분리한다.
- 전문 검토 평가는 모든 포함 문서가 연속 구간 대장과 독해 메모를 가지는지, scanner만으로 전문 검토를 주장하지 않는지를 별도로 확인한다.
- 생성 품질 평가는 적어도 두 분류를 갖춘다. `raw_ai`나 의도적 합성문은 실제 해체 능력을, `human_polished`는 과교정 억제를 검증한다.
- `ai_edited` 장문 평가는 문장별 표지와 별도로 장·파일 간 메타 발화, 회귀 신호, 예고 문구, 굵은 라벨 연쇄의 위치·분포를 평가한다. 반복의 존재만으로 감점하거나 자동 삭제하지 않는다.
- 다의어 이관 평가는 전역 단일 치환 fixture와 용례별 `replace·preserve·ask` 대장 fixture를 분리한다. 같은 줄에 여러 용례가 있을 때에도 변경 전·후 좌표가 맞는지 검증한다.
- 거칠지만 강한 원문과 매끈하지만 평범해진 윤문본, 감정·판단의 긴 연쇄와 명제만 남긴 압축본을 대조군으로 둔다.
- 문학·에세이에서는 양가성·거리·인지적 긴장을 일반적인 교훈이나 공감의 결론으로 바꾼 후보를 실패 대조군으로 둔다.
- KH-S40 평가는 의미 중복 삼항 연쇄, 서로 다른 실제 절차, 법률 요건, 직접 인용, 의도적 점층을 분리한다. 삼항 구문의 존재나 감소만으로 통과·실패를 판정하지 않는다.
- 축약 불가 연쇄 평가는 앵커 순서만 남긴 압축본과 단계 사이의 관찰·오해·변화를 보존한 후보를 분리한다.
- 출처의 주장·전언·추정·유보·반대 심문을 사실이나 최종 결론으로 승격한 후보를 충실성 실패 대조군으로 둔다.
- 빈 추상명사를 유사한 추상어로 바꾼 후보, 같은 문단의 근거로 내용을 채운 후보, 원문에 없는 구체를 만든 후보를 분리한다.
- 자기해설 한 문장만 지워 문단 잔재를 남긴 후보, 문단 전체에서 새 정보·귀속·전환을 보존한 후보, 필요한 이행까지 지운 후보를 분리한다.
- 반복 저자 검토에서는 high·medium·low 분류와 실제 채택·기각 이유를 프로젝트 내부에서 비교하되, 채택률을 공개 품질 임계값으로 쓰지 않는다.
- 강조 제거 시험은 선두 볼드가 빠진 뒤 남은 단독 라벨, 연속 나열, 완전한 문장, 질문·번호 표지를 서로 다른 대조군으로 둔다.
- 원문·후보 A·후보 B의 순서를 가린 상태에서 평가한다.
- 장문 평가에서는 사용자가 지정한 독자군·읽는 상황·우선순위를 기록하고, 지정이 없으면 보편 독자 선호를 주장하지 않는다.
- 장문·서사성 원고의 대조군에는 출발 질문·전환·열린 결말을 성급한 교훈이나 요약으로 평탄화한 후보를 넣는다. `return`·`qualification`·`open`의 구분은 [reader-fit-and-trajectory.md](reader-fit-and-trajectory.md)를 따른다.

## 통과 조건

| 축 | 통과 조건 |
| --- | --- |
| 보호 | 수치·날짜·이름·직접 인용·사용자 보호 구간이 보존된다. |
| 충실성 | 주장, 부정, 주체, 양태, 인과 관계, 인용 귀속과 인식 지위에 변경이 없다. 윤문본의 모든 명제가 원문의 `의미 명세`에 대응한다. |
| 표지 완화 | 수정 대상으로 선언한 결정적 표지가 실제로 줄었다. 그대로 두는 경우는 사람이 문맥을 확인하고 보존 사유를 기록한다. |
| 재구성 | 표준 인간화에서 단어 치환만 하지 않고, 필요한 문단은 주제문·근거·예시·예외의 실제 진행으로 다시 짰다. |
| 목소리 | 원고의 강한 구간과 문장 시작·종결·호흡·구체성 범위가 큰 충돌 없이 어우러진다. |
| 강점 보존 | 강점 대장의 `exact` 표현이 남고, `functional` 항목의 초점·거리·리듬·지연 효과를 사람이 보존으로 판정한다. |
| 과정 보존 | 감정·판단의 누적, 정보 지연, 장면 회귀 등 축약 불가 연쇄의 순서와 단계 사이의 전개가 유지되고 결론이 앞당겨지지 않는다. |
| 인지적 거리 | 낯선 관점·불일치·동일시되지 않는 목소리를 익숙한 공감이나 교훈으로 바꾸지 않는다. |
| 잔존성 | 새 재료를 만들지 않고도 문단 뒤에 구체적 장면·구별·긴장·저자의 시선 가운데 하나가 남는다. |
| 과교정 방지 | 새 사실·인용·비유·상투구를 넣지 않고 장르·격식을 바꾸지 않는다. |
| 자연스러움 | 순서를 가린 사람 평가에서 원문보다 자연스럽거나 동등하다고 판단된다. |
| 독자 적합성 | reader_profile이 있을 때에만, 지정한 독자·읽는 상황·우선순위에 맞는지 순서를 가린 사람 평가로 판단한다. |
| 장문 전개 | trajectory_ledger를 사용했을 때, 출발 약속·전환·끝 상태의 관계가 보존되고 성급한 봉합이나 새 결말이 생기지 않는다. |
| 용어 이관 | 확정어가 term map 범위에서 일관되며, 확정어 자체를 변주하지 않고 이관 뒤 생긴 동어반복·호응·연어·개념 범위를 사람 문맥으로 검토했다. |
| 선별 이관 | 모든 기존어 용례가 하나의 의미·결정·변경 전 좌표에 대응하고, `replace·preserve`의 변경 후 좌표도 확인된다. `ask`가 남아 있으면 완료로 주장하지 않는다. |

무수정은 두 경우를 구분한다. 수정 대상을 선언하고도 표지를 그대로 둠으면 실패다. `human_polished`에서 지배 패턴이 없다고 판정하고 수정하지 않았다면 과교정 방지 성공으로 기록할 수 있다. 문자 변경률은 경보용 보조 지표일 뿐, 낮은 변경률만으로 통과를 선언하지 않는다. 정량 임계값은 공개·blind 평가가 쌓이기 전에는 정하지 않는다.

## 범위 주장 통과 조건

- `전수 분류`는 모든 scanner 앵커가 ledger에 한 번씩 있고, 기계·사람·제외 중 하나로 분류된 경우에만 쓴다.
- `전수 문맥 검토`는 모든 앵커가 사람이 읽은 문맥 판정과 이유를 가진 경우에만 쓴다.
- 인용·보호 블록·주석·코드는 앵커 모집단에서 왜 제외됐는지 결과 receipt로 남긴다.
- 타당한 반복을 변주하는 제안은 적어도 하나의 보존 대조군과 의미·논리 관계 훼손 위험을 함께 제시해야 한다. 자동 교체는 실패다.

## 평가자 편향 억제

- 평가자에게 후보의 도구명·버전·개발 의도를 알리지 않는다.
- 합성문은 “모두 고치기”가 아니라 자연스러움과 충실성을 함께 점수화한다.
- 이미 좋은 원고에서는 원문 선호를 허용한다. 다만 보존 사유를 구체적으로 적게 한다.
- 모델 평가는 전방 검증으로 기록하고, 사람 평가를 대체했다고 표현하지 않는다.
- 같은 초안을 3~5회 반복 적용하는 수렴 시험을 둔다. 2차 이후에는 최초본과 직전본을 함께 제공하고, 새 `edit` 항목이 없을 때 무수정으로 멈추는지 확인한다.
- 반복 시험은 의미 손실 복구, 해결한 위치의 재수정, 표현 왕복, 없앤 공식의 재도입, 무수정 뒤 재수정을 실패 조건으로 기록한다. 최종 회차가 아니라 gate를 통과한 최선의 회차를 채택한다.
- receipt가 `보호값·형식·목표 감소·의미 대조 통과`를 주장하면 실제 실행 기록과 대조 근거가 있어야 한다. 실행하지 않은 검증을 통과로 적은 결과는 본문 품질과 별개로 실패다.
- 용어 이관의 기계 감사가 통과해도 모든 확정어 용례의 연어·개념 범위를 사람이 읽지 않았다면 `전수 용어 검토`를 주장하지 못한다.
- `ai_edited` 구조 후보가 줄었다는 사실만으로 장문 전체의 목소리·구성·반복을 개선했다고 주장하지 못한다. 위치와 반복 분포는 사람의 재독 우선순위다.
- 문법 오류와 상투구가 줄어도 강점 대장이나 축약 불가 연쇄를 잃었으면 실패다. 결함의 부재를 강점의 존재로 대신 측정하지 않는다.

# 작성 전 점검

아직 쓰지 않은 원고에 K-humanizer를 적용할 때 쓰는 짧은 브리프다. 이 문서는 문장을 대신 쓰거나, 모든 문체 표지에 수치 상한을 부여하지 않는다. 장르·독자·원고의 강점을 먼저 정하고, 쓴 뒤 다시 읽어야 할 위치를 정한다. 프로젝트가 승인한 수치·화자·강조·이행 규칙이 있으면 [project-style-profile.md](project-style-profile.md)에 따로 둔다.

## 산출 형식

1. 장르·독자·격식과 사용할 `provenance: rule_guided_draft`를 적는다.
2. `측정`·`보존`·`재독` 세 칸만 가진 표를 만든다.
3. 초고 뒤 `scan_style.py --provenance rule_guided_draft`를 실행하고, 문맥을 읽어 `edit·preserve·ask·false_positive`를 판정한다.

| 구분 | 무엇을 적나 | 금지할 오해 |
| --- | --- | --- |
| 측정 | 다시 읽을 규칙·문단 리듬·문장 안 연쇄 | 횟수 자체가 결함이나 품질 점수라는 해석 |
| 보존 | 장르가 요구하는 제목·용어·약어·인용·표의 기능 | 보호를 핑계로 문단 전체를 검사에서 제외하는 일 |
| 재독 | 문장을 쪼개거나 합친 뒤 생길 수 있는 리듬·논리 손실 | 한 규칙을 줄이려고 다른 결함을 만드는 일 |

## 수치 사용 원칙

공개 비교 근거와 모집단 정의가 없는 한 기본 상한은 만들지 않는다. 특히 다음 값은 경보용 관찰치다.

- `single_sentence_paragraph_ratio`: Markdown 본문 문단 중 한 문장 문단의 비율이다. 제목·인용·목록·표·구분선은 제외한다.
- KH-S07 총계: 연결어미 뒤 쉼표의 문서 전체 수다. 총계가 아니라 `max_per_sentence`와 `sentences_with_2plus`로 한 문장 안의 연쇄를 먼저 읽는다.
- 강조·목록·표의 비율: 장르와 독자 요구를 확인한 뒤에만 해석한다.

프로젝트 고유의 수치 목표가 꼭 필요하면, 비교 대상·모집단·보존 예외·실패 시 대응을 함께 기록한다. 그 목표는 K-humanizer의 보편 기준이라고 쓰지 않는다.

## 과교정 방지

- KH-S01 같은 대조를 줄인다고 문장을 기계적으로 나누지 말고, 남길 대조와 직접 서술할 내용을 먼저 결정한다.
- 삭제 후보만 예상하지 말고, 논증을 떠맡은 빈 추상명사에 같은 문단이 실제 답을 주는지도 재독 항목으로 둔다.
- 자기해설은 문장 목록이 아니라 문단 기능으로 판정하며, 지웠을 때 사라지는 새 정보·귀속·전환을 기록한다.
- 문장 분할·통합 뒤에는 전후 `paragraph_rhythm`을 비교한다. 비율이 바뀌었다는 사실만으로 실패라고 하지 말고, 새 문단이 독립 장면·논점·전환을 가지는지 읽는다.
- 제목의 대조, 번호 병렬, 약어 병기처럼 장르가 요구하는 요소는 [genre-allowlist.md](genre-allowlist.md)로 규칙과 범위를 좁혀 선언한다.
- 구조 규칙이 의도적으로 필요해도 `rule_guided_draft` 결과의 `scope_warnings`를 확인한다. 건너뛴 규칙이 있으면 전수 진단이라고 말하지 않는다.

## 최소 예시

```text
장르: 법률·생활 정보서 / 독자: 일반 독자 / 격식: 설명체
내력: rule_guided_draft

측정: KH-S01은 논증 대조인지 확인; KH-S07은 한 문장 안의 연쇄만 재독;
      paragraph_rhythm은 문장 분할 뒤 전후 비교.
보존: 정식 기관명과 약어, 판정 제목의 대조, 직접 인용.
재독: 대조를 덜며 문단을 쪼갰다면 새 문단의 독립 기능과 인과 관계 확인.
```

이 브리프는 초고의 표현을 미리 금지하는 검사표가 아니다. 쓰는 동안 실제 논증과 목소리를 우선하고, 초고 뒤에 위치 후보를 다시 읽을 수 있게 하는 작업 계약이다.

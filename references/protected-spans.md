# 보호 구간 v0.1

기본 보호 구간은 직접 인용, 날짜, 수치·단위, 조문 표기다. 사용자가 지정한 문자열은 이 기본 목록에 더한다. 이 목록은 의미 검증의 전부가 아니라 **변경하면 중단해야 하는 최소 안전망**이다.

- 보호값은 윤문 전후에 같은 횟수 이상 그대로 남아야 한다.
- 동음 반복 값 때문에 위치까지 일치시키지 못하는 경우에는 검증 결과를 `확인 요청`으로 처리한다.
- 이름·전문용어·각주·제목처럼 자동 추출이 어려운 구간은 `--protect-file` 또는 사용자 보호 지시로 추가한다.
- 보호값을 바꿀 필요가 있으면 기계적으로 통과시키지 않고, 수정 이유와 대안을 저자에게 확인한다.

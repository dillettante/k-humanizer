# 보호 구간 v0.3

기본 보호 구간은 직접 인용, Markdown 인용 블록, 명시 보호 블록, 날짜, 수치·단위, 조문 **인용 표기**(예: `제30조`)다. 사용자가 지정한 문자열은 이 기본 목록에 더한다. HTML 주석과 fenced code block은 보호값 검증 대상과 별개로 산문 스캔에서 가린다. 이 목록은 의미 검증의 전부가 아니라 **변경하면 중단해야 하는 최소 안전망**이다.

- 보호값은 윤문 전후에 같은 횟수 이상 그대로 남아야 한다.
- 동음 반복 값 때문에 위치까지 일치시키지 못하는 경우에는 검증 결과를 `확인 요청`으로 처리한다.
- 이름·전문용어·각주·제목처럼 자동 추출이 어려운 구간은 `--protect-file` 또는 사용자 보호 지시로 추가한다.
- 보호값을 바꿀 필요가 있으면 기계적으로 통과시키지 않고, 수정 이유와 대안을 저자에게 확인한다.
- 법령·판결문 본문을 따옴표 없이 옮겨 실은 경우에는 자동으로 잡지 않는다. 조문 표기만으로 그 문단 전체를 자동 보호하면 일반 산문까지 과도하게 제외할 수 있기 때문이다. 조문 전문·표·인용 전문처럼 손대면 안 되는 덩어리는 `<!-- k-humanizer:protect-start -->`와 `<!-- k-humanizer:protect-end -->` 사이에 넣거나 `--protect-file`에 넣는다.
